**작성일:** 2026-05-21
**상태:** 승인됨

---

## 1. 프로젝트 개요

### 앱 개념
사용자의 실제 카카오톡 대화 데이터와 행동 성향을 기반으로 "디지털 페르소나"를 생성하고, 그 페르소나를 다양한 가상 상황 속에 배치하여 현실에서 경험하기 어려운 인간 관계, 감정, 선택을 인터랙티브하게 시뮬레이션하는 모바일 애플리케이션.

### 핵심 가치
- AI 챗봇이 아닌 **관계 연습 및 사회적 기술 훈련 도구**
- 자기 이해(A), 감정 체험(B)은 보조 목적
- 실제 카톡 데이터 기반의 **진짜 나 / 진짜 지인** 모델링으로 차별화

### 타겟 사용자
- 20-30대 일반 사용자 (연애, 직장, 친구, 가족 관계 고민)
- 사회불안·대인관계 어려움을 겪는 사람
- 커뮤니케이션 스킬을 의도적으로 향상하고 싶은 사람

## 2. 기술 스택

| 레이어 | 기술 | 이유 |
|---|---|---|
| 모바일 앱 | Flutter (Dart) | iOS + Android 단일 코드베이스, 풍부한 UI 자유도 |
| 백엔드 | Python FastAPI | LLM API 연동 생태계 성숙, 비동기 스트리밍 지원 |
| AI | Claude API (Anthropic) | 페르소나 모델링, 시나리오 생성, 피드백 분석 통합 |
| 데이터베이스 | PostgreSQL | 페르소나 프로파일, 시뮬레이션 기록 영구 저장 |
| 통신 | HTTPS + WebSocket | REST API + 실시간 대화 스트리밍 |

## 3. 핵심 기능 3가지

### 기능 ① 페르소나 프로파일링

**목적:** 카카오톡 대화 파일을 분석해 나와 지인의 심리 프로파일을 생성·시각화

**카톡 파일 처리 흐름:**
```
.txt 파일 업로드
  → 파싱 (날짜 / 발화자 / 내용 분리)
  → 내 발화 추출 → 나의 페르소나 생성
  → 상대방 발화 추출 → 지인 페르소나 생성
  → Claude API로 심리 프로파일 분석
  → DB 저장 후 앱에 전달
  → 원본 파일 서버에서 즉시 삭제
```

**프로파일 항목:**
- 말투 스타일 (직접적 ↔ 우회적)
- 감정 표현 빈도
- 주요 반응 패턴 (공감형 / 해결형 / 회피형)
- 자주 쓰는 표현 Top 10
- 대화 주도성 점수

**페르소나 카드 UI:**
```
┌──────────────────────────────┐
│  👤 김철수                    │
│  마지막 업데이트: 2025.05.01   │
│  대화 데이터: 3,240개 메시지   │
│                              │
│  직접적 ████████░░ 80%       │
│  감정표현 █████░░░░░ 50%      │
│  공감형   ███░░░░░░░ 30%      │
│                              │
│  [시뮬레이션] [업데이트] [삭제] │
└──────────────────────────────┘
```

### 기능 ② 하이브리드 시뮬레이션

**구조:** 템플릿 모드(진입용) + 자유 모드(심화용)

**템플릿 모드:**
```
카테고리 선택
  ├── 연애 (고백, 갈등, 이별)
  ├── 직장 (상사와 갈등, 피드백 요청)
  ├── 친구 (오해 해소, 부탁 거절)
  └── 가족 (기대 부담, 감정 표현)
    ↓
상대 페르소나 선택 (등록된 지인 or AI 생성 인물)
    ↓
시뮬레이션 시작
```

**자유 모드:**
```
사용자 직접 입력
  - 상황 설명 (자유 텍스트)
  - 목표 설정
  - 감정 톤 선택 (차분히 / 솔직하게 / 감정적으로)
    ↓
Claude가 시나리오 구성 → 시뮬레이션 시작
```

**대화 화면 구성:**
```
┌─────────────────────────────┐
│  [상대 페르소나 이름 + 프로필]  │
│  상황: "카페에서 만남"          │
├─────────────────────────────┤
│                             │
│  [상대] 어... 그게 사실이야.    │
│                             │
│          [나] 왜 말 안 했어? │
│                             │
│  [상대] 미안, 네가 걱정할까봐. │
│                             │
├─────────────────────────────┤
│ 💾 세이브포인트  📊 현재 감정  │
├─────────────────────────────┤
│  [메시지 입력창]        [전송] │
└─────────────────────────────┘
```

- **세이브포인트:** 언제든 해당 시점으로 돌아와 다른 선택 탐색 가능
- **현재 감정 지표:** 대화 흐름에 따라 긴장도/공감도 실시간 표시

---

### 기능 ③ 리플레이 & 피드백

**피드백 리포트 (시뮬레이션 종료 후):**
```
📊 오늘의 대화 패턴
  - 회피형 반응: 3회
  - 감정 직접 표현: 1회
  - 공감 시도: 2회

💡 인사이트
  "갈등 상황에서 감정을 직접 표현하기보다
   화제를 전환하는 경향이 있어요."

🔄 리플레이 추천 포인트
  → 3번째 대화에서 다르게 말했다면?
```

**리플레이 분기 탐색:**
- 세이브포인트에서 다른 선택 입력
- Claude가 해당 선택에 따른 대화 흐름 새로 생성
- 여러 분기 비교 가능

## 4. 페르소나 생애주기 (지속 학습)

### 페르소나 상태 모델
```
생성
  → [활성 페르소나] ← 신규 대화 추가 시 지속 업데이트
       ↓ 누적될수록 정확도 향상
  → [보관] (비활성화, 데이터 유지)
       ↓ 사용자 선택 시
  → [삭제] (완전 제거)
```

### 업데이트 방식
- 신규 카톡 파일 업로드 시 기존 프로파일과 **가중치 병합 분석**
- 최신 데이터에 더 높은 가중치 적용
- 변화 감지 및 알림: "최근 6개월간 감정 표현이 15% 증가했어요"

### 업데이트 히스토리
```
페르소나 타임라인
  ├── 2024.01 생성 (초기 분석)
  ├── 2024.06 업데이트 (+6개월 대화)
  └── 2025.01 업데이트 (+최근 대화)
        → 시기별 변화 비교 가능
```

## 5. 시스템 아키텍처

```
[Flutter 앱]
     ↕ HTTPS / WebSocket
[Python FastAPI 서버]
     ├── 카톡 파서 (텍스트 분석)
     ├── 페르소나 생성 엔진 (Claude API)
     ├── 시뮬레이션 엔진 (Claude API + 스트리밍)
     └── 피드백 분석기 (Claude API)
          ↕
     [PostgreSQL DB]
     ├── 사용자 계정
     ├── 페르소나 프로파일
     ├── 시뮬레이션 기록
     └── 피드백 리포트
```

### 데이터 모델 (핵심)

**personas 테이블**
```
id, user_id, name, type(self/acquaintance),
profile_json, message_count, created_at, updated_at
```

**simulations 테이블**
```
id, user_id, persona_id, scenario_type(template/free),
scenario_config_json, turns_json, savepoints_json,
feedback_json, created_at
```

## 6. 앱 화면 구조

```
├── 온보딩 / 카카오톡 파일 업로드
├── 홈 (내 페르소나 카드 + 지인 페르소나 목록)
├── 페르소나 상세 (심리 분석 시각화 + 타임라인)
├── 시뮬레이션
│   ├── 템플릿 선택
│   ├── 자유 설정
│   └── 대화 화면 (세이브포인트 + 감정 지표)
├── 피드백 리포트
├── 리플레이 탐색기
└── 설정 / 구독 관리
```
